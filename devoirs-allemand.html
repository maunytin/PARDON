Übung — Correction

Pronom + verbe + nom, à l'accusatif ou au datif

  1. Ich träume von der Reise nach Berlin.
    → Ich träume von ihr.
  2. Sie denkt an das Diplom.
    → Sie denkt an es.
  3. Wir denken an die Zukunft.
    → Wir denken an sie.
  4. Er träumt von der Liebe.
    → Er träumt von ihr.
  5. Sie träumen von dem besseren Leben.
    → Sie träumen von ihm.
  6. Ich träume von dem Reichtum.
    → Ich träume von ihm.
  7. Träumst du von dem Strand?
    → Träumst du von ihm?
  8. Denkt ihr an die Hausaufgaben?
    → Denkt ihr an sie?
Pardon pour les fautes... mais pas pour les sentiments 💕
